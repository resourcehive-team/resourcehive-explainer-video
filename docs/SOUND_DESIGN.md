# Sound design

Voice is primary. Use one quiet music bed, ducked under every voice segment and raised only briefly between segments. Final audio will be checked for clipping.

| Event | Cue | Level |
| --- | --- | --- |
| Title reveal | `logo-impact` | subtle |
| Product-to-architecture transition | `transition-major` | moderate |
| Booking success | `success` | subtle |
| Architecture node reveal | `node-enter` | sparse |
| Request movement | `request-move` | sparse |
| Ordinary labels, small fades | silent | — |

If sound files are supplied, place them in `public/audio/sfx/` with those names and `.mp3` extensions. Missing optional cues are simply omitted.
